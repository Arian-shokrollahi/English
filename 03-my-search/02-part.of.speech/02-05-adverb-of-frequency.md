# قید تکرار چیست؟
قید تکرار(Adverb of frequency) کلمه یا عبارتی است که میگوید یک کار را چند وقت یکبار انجام میدهیم یعنی میزان تکرار یک اتفاق رو نشون میده.


## اول بریم سراغه قید هایه تکرار
| قید تکرار(adverb of frequency) | معنی           | درصد تقریبی |
| ------------------------------ | -------------- | ----------- |
| Always                         | همیشه          | 100%        |
| Almost always                  | تقریبا همیشه   | 95%         |
| Usually                        | معمولا         | 90%-80%     |
| normally/generally             | معمولا/عموما   | 80%-70%     |
| often/frequently               | اغلب/زیاد      | 70%-        |
| sometimes                      | گاهی           | 50%-40%     |
| occasionally                   | گاه به گاه     | 30%-20%     |
| rarely/seldom                  | به ندرت        | 10%-5%      |
| hardly ever                    | تقریبا هیچ وقت | 5%-1%       |
| never                          | هرگز /هیچ وقت  | 0%          |
## جایگاه قید هایه تکرار درون جمله
- 1-قبل از فعل اصلی
- 2-بعل فعل توبی
- 3-با فعل کمکی،بعد از فعل کمکی
```
ex model 1
-I usually study English at night.
-She never drinks coffe.
------
ex model 2
-He is always late
-They are sometimes busy
------
ex model 3
-I have never seen that movie.
-She can usually help you.
```
### عبارت‌های تکرار رایج

این‌ها هم معنی تکرار می‌دهند، ولی معمولاً اول یا آخر جمله می‌آیند:

- ا-**every day** → هر روز
- ا-**once a day / week** → یک‌بار در روز / هفته
- ا-**twice a week** → دو بار در هفته
- ا-**three times a month** → سه بار در ماه
- ا-**on Mondays** → دوشنبه‌ها
- ا-**at weekends / on weekends** → آخرهفته‌ها
- ا-**from time to time** → هر از گاهی
- ا**now and then** → گاهی اوقات
- ا-**every once in a while** → هر از چند گاهی
