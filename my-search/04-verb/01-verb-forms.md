# 01-04-فرم هایه فعل ها 
---
## فرم هایه فعل (verb forms)چیست؟
فرم هایه فعل یعنی حالت هایی که یک فعل میتواند بگیرد و این نکته رو در نظر بگیرد فعل میتواند این فرم هارو داشته باشد ولی تایپ هایه مختلفی دارد پس این نکته رو در نظر بگیرید که : فرم هایه فعل و تایپ هایه فعل با هم دیگر فرق دارند .
- فرم هایه فعل میشه--->حالت هایی که میتونه فعل بگیره(V1, V2, V3, V-ing, V1 third person singular)
- تایپ هایه فعل میشه--->modal verb, auxiliary verb, phrasal verb,...etc
--- 
این خلاصه ای از فرم هایه فعل است

| Form  | name                      | example with write | example with go | کاربرد اصلی                                        |
| ----- | ------------------------- | ------------------ | --------------- | -------------------------------------------------- |
| V1    | baseform/infinitive       | write              | go              | حال ساده،بعد از modal،do, does, did                |
| V1+s  | Third-person singular     | writes             | goes            | حال ساده با it she he با دومدل با قاعده و بی قاعده |
| V2    | past simple               | wrote              | went            | گذشته ساده                                         |
| V3    | past participle           | written            | gone            | perfect & passive                                  |
| V-ing | present participle/gerund | writing            | going           | continuous                                         |

## 1)مدل ساده (base form)(V1)
این همان شکل اصلی فعل است شکلی که در دیکشنری میبینی:           write, work, go, eat, study  
##### کاربرد هایه مدل 1
- 1-در حال ساده(present simple) با I/You/They/We
- 2-بعد از (modal verb)---> بعد مدال verb همیشه در حالت ساده میاید
- 3-بعد do , does, did فعل اصلی (v1)میاد همیشه
```
1- in present simple with I/You/They/We
I work every day.
من هر روز کار می‌کنم.

They study English.
آن‌ها انگلیسی می‌خوانند.
------
2- after modal verb
She can write.
او می‌تواند بنویسد.

You should go.
تو بهتر است بروی.
------
3- after do/does/did
do you work here?
she does't work here
did you go yesterday
```
#### تو این قسمت درمورد modal verb ها هم بریم بخونیم
- فعل هایه مدال(modal verb) چیست ؟**Modal verb**ها دسته‌ای از فعل‌های کمکی هستند که معنی اصلی جمله را نمی‌سازند، بلکه به فعل اصلی اضافه می‌شوند تا مفهوم‌هایی
```
can      // توانایی، اجازه، امکان
could    // توانایی در گذشته، درخواست مؤدبانه، احتمال
may      // اجازه رسمی‌تر، احتمال
might    // احتمال (معمولاً ضعیف‌تر یا نامطمئن‌تر از may)
must     // اجبار خیلی قوی، یا نتیجه‌گیری تقریباً قطعی
should   // توصیه، نصیحت، کاری که بهتر است انجام شود
will     // آینده، تصمیم لحظه‌ای، قول یا پیش‌بینی
would    // درخواست مؤدبانه، حالت فرضی، تمایل
shall    // پیشنهاد یا نظرخواهی؛ بیشتر با I / we و در بریتیش انگلیش
---
I can swim.                    // می‌توانم شنا کنم.

Could you help me?             // می‌شود کمکم کنی؟ (مودبانه)

May I come in?                 // اجازه دارم وارد شوم؟ (رسمی)

It might rain tonight.         // شاید امشب باران ببارد.

You must wear a helmet.        // حتماً باید کلاه ایمنی بپوشی.

You should sleep earlier.      // بهتر است زودتر بخوابی.

I will call you tomorrow.      // فردا به تو زنگ می‌زنم.

Would you like some coffee?    // قهوه میل دارید؟ (مودبانه)

Shall we begin?                // شروع کنیم؟
```

## 2)مدل سوم شخص مفرد حال ساده (V1+s — Third-Person Singular Form):
- این شکل برای **حال ساده** و فقط با فاعل مفرد سوم‌شخص استفاده می‌شود:
```
he / she / it / Ali / the server
---
He works every day.
او هر روز کار می‌کند.

She studies English.
او انگلیسی می‌خواند.

The server runs Linux.
سرور لینوکس اجرا می‌کند.
```

- قوانین ساخت V1+s چیست؟ دومدل برایه ساخت دارد: با قاعده و بی قاعده

| شکل فعل V1+s             | تغییر             | مثال                              |
| ------------------------ | ----------------- | --------------------------------- |
| اغلب فعل ها              | +s  (regular)     | work->works                       |
| پایان با o,z,x,s,s,sh,ch | +es  (regular)    | watch->watches/go-->goes/do->does |
| پایان صامت+y             | y->ies  (regular) | study->studies                    |
| پایان مصوت+y             | +s   (regular)    | play->plays                       |
| have/                    | irregular         | have->has &                       |

## 3)مدل سوم-V2(past simple)
مدل **V2** برای ساختن **گذشتهٔ ساده** است: کاری که در گذشته رخ داده و تمام شده است
- در این قسمت به برسی سه چیز خواهم پرداخت
- 1-حالت V2 با قاعده (regular)
- 2-حالت V2 بی قاعده (irregular)
- 3-و در کجاها در گذشته ساده فعل در حالت base میاد
--
- 1-ساخت فعل هایه V2 با قاعده با اضافه کردن ed+ به فعل صورت میگیرد.
```
V1+ed
work->worked
play->played
watch->watched
```
- 2-فعل هایه مدل 2 گذشته بی قاعده که قاعده ای ندارند و باید حفظ کنی
```
go → went
write → wrote
eat → ate
see → saw
```
- 3-در جاهایی که did /didn't باشد فعل در حالت ساده میاد
- مرور در حال ساده جاهایی که does میومد حالت ساده میشدن اون سوم شخصا
```
She went yesterday.        ✅
Did she go yesterday?      ✅
She didn't go yesterday.   ✅

Did she went yesterday?    ❌

```

## 4)شکل سوم فعل یا(past participle &  V3)
این نوع فعل ها هم دو مدل دارند با قاعده و بی قاعده:
- 1-با قاعده(regular) ها مثل شکل دوم فعل هستند و از حالت اول +ed ساخته میشوند.
- 2-بی قاعده(irregular) ها مثل با قاعده ها نیستند و باید حفظ شوند
```
regular:
work → worked → worked
play → played → played
---
irregular
go → went → gone
write → wrote → written
eat → ate → eaten
see → saw → seen
```
#### کاربرد هاش در دو چیز است 1-زمان هایه کامل(perfect tenses) & 2-جمله مجهول(passive voice)
##### 1-مدل اول زمان هایه کامل(perfect tenses)
##### 2-مدل دوم جمله مجهول(passive voice)
--
###### مدل1 یک زمان هایه کامل (perfect tenses)
```
formol : have / has / had + V3
---ex
I have finished the task.
من کار را تمام کرده‌ام.

She has written the report.
او گزارش را نوشته است.

They had gone home.
آن‌ها به خانه رفته بودند.

```
###### مدل2 جمله مجهول(passive voice)
```
formol : be + V3
---ex
The file was deleted.
فایل حذف شد.

The report is written in English.
گزارش به انگلیسی نوشته شده است.

```

## 5)فرم پنج فعل ( V-ing(present participle/gerung))
این مدل شکل verb-ing است
```
work → working
write → writing
go → going
run → running
```
#### چند نمونه از کاربرد
- کاربرد1 زمان هایه استمراری
- کاربرد2 وقتی فعل نقشه اسم دارد (gerund
```
formol-->be + V-ing
--
karbord1:
I am studying now.
من الآن در حال درس خواندن هستم.

They were working yesterday.
آن‌ها دیروز در حال کار کردن بودند.
--
karbord2:
Reading is useful.
خواندن مفید است.

I like learning English.
من یاد گرفتن انگلیسی را دوست دارم.

```

## چند قانون املایی برایه فعل هایی که ing میگیرند:
| حالت                                 | قانون                | مثال            |
| ------------------------------------ | -------------------- | --------------- |
| بیشتر فعل ها                         | +ing                 | work-->working  |
| پایان e بیصدا                        | e del+add-ing        | write->writing  |
| پایان ie                             | ie del->y+ing        | lie->lying      |
| فعل کوتاه: consonant-vowel-consonant | lastword double+-ing | run->running    |
| پایان y                              | only add +-ing       | study->studying |
