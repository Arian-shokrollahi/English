# Past Verb / V2

## اول: کجاها V2 استفاده می‌شود؟

1. **Past Simple** → مهم‌ترین کاربرد
2. **جملات مثبت در گذشته ساده**
3. **بعد از بعضی ساختارهای روایی/گذشته** که فعل اصلی در گذشته می‌آید
4. **افعال باقاعده و بی‌قاعده** → Regular / Irregular Verbs

> نکته خیلی مهم: برخلاف Base Verb، **بعد از `did` از V2 استفاده نمی‌کنیم**؛ بعد از `did` همیشه Base Verb می‌آید.

---

# 1. Past Simple

مهم‌ترین کاربرد V2، **Past Simple** است.

ساختار:

```
Subject + V2 + Object
```

مثال:

> I **worked** yesterday.  
> She **visited** her friend.  
> We **learned** Linux.  
> He **went** home.

اینجا:

- `worked` → V2
- `visited` → V2
- `learned` → V2
- `went` → V2

---

# 2. Regular Verbs

افعال باقاعده معمولاً برای ساخت V2، `-ed` می‌گیرند.

مثلاً:

|Base Verb|V2|
|---|---|
|work|worked|
|learn|learned|
|start|started|
|stop|stopped|
|help|helped|
|use|used|
|open|opened|
|play|played|

مثال:

> I **work** every day.  
> I **worked** yesterday.

---

# 3. Irregular Verbs

افعال بی‌قاعده قانون `-ed` ندارند و باید V2 آن‌ها را یاد بگیری.

مثلاً:

|Base Verb|V2|
|---|---|
|go|went|
|come|came|
|see|saw|
|take|took|
|give|gave|
|get|got|
|make|made|
|know|knew|
|think|thought|
|find|found|

مثال:

> I **go** to work every day.  
> I **went** to work yesterday.

---

# 4. سؤال و منفی در Past Simple

اینجا یک نکته **خیلی مهم** وجود دارد.

وقتی `did` داریم، فعل اصلی به **Base Verb** برمی‌گردد.

### مثبت:

> I **went** home.

### سؤال:

> Did you **go** home?

### منفی:

> I did not **go** home.

پس:

```
Positive:
Subject + V2

Question:
Did + Subject + Base Verb?

Negative:
Subject + did not + Base Verb
```

❌ Did you **went**?  
✅ Did you **go**?

❌ I didn't **went**.  
✅ I didn't **go**.

---

# 5. تفاوت Base Verb و V2

این تفاوت را خیلی خوب یاد بگیر:

|Base Verb|V2|مثال|
|---|---|---|
|go|went|I **went** home.|
|work|worked|I **worked** yesterday.|
|see|saw|I **saw** him.|
|take|took|I **took** the file.|
|learn|learned|I **learned** Linux.|

یعنی:

**Base Verb = شکل اصلی فعل**

**V2 = شکل گذشته فعل**

### خلاصه نهایی

```
V1 = Base Verb
V2 = Past Verb
```

مثلاً:

```
go → went
work → worked
see → saw
take → took
learn → learned
```

و مهم‌ترین قانون:

```
Past Simple مثبت:
Subject + V2

Past Simple سؤال:
Did + Subject + V1?

Past Simple منفی:
Subject + didn't + V1
```

مثلاً:

> I **went** there.  
> Did you **go** there?  
> I didn't **go** there.

**پس V2 عمدتاً در جمله مثبت Past Simple دیده می‌شود؛ وقتی `did/didn't` وارد جمله شود، فعل اصلی دوباره V1 می‌شود.**
