## ا-Base Verb (V1) یعنی چی؟

ا-**Base verb** یعنی شکل اصلی و ساده‌ی فعل؛ همون شکلی که معمولاً در دیکشنری می‌بینی و هنوز هیچ تغییری مثل `-s`، `-ed` یا `-ing` نگرفته.

---
## جاهایی که Base Verb استفاده می‌شود

قبل از اینکه وارد توضیح بشیم، این کاربردهای اصلی رو داشته باش:

1. **Present Simple** → با `I / You / We / They`
2. **Modal Verbs** → بعد از `can, could, should, must, may, might, will...`
3. **do / does / did** → بعد از آن‌ها
4. **Imperative** → برای دستور دادن
5. **Infinitive with to** → به شکل `to + base verb`
6. **بعد از بعضی افعال خاص** → مثل `let, make`
7. **جملات شرطی** → در بعضی ساختارهای Conditional

---

## 1. Present Simple

در Present Simple وقتی فاعل:

`I / You / We / They`

باشد، از **Base Verb** استفاده می‌کنیم.

> I **work** every day.  
> You **learn** Linux.  
> We **use** Linux.  
> They **run** the server.

اما:

`He / She / It → verb + s/es`

> He **works** every day.  
> She **uses** Linux.

پس:

**I work** ✅  
**He works** ✅

---

## 2. بعد از Modal Verbs

بعد از Modal Verb همیشه **Base Verb** می‌آید.

ساختار:

```
Subject + Modal + Base Verb
```

مثل:

`can, could, should, must, may, might, will, would`

مثال:

> I **can learn** Linux.  
> You **should study** more.  
> We **must work** harder.  
> He **can use** Linux.

دقت کن:

❌ He can **uses** Linux.  
✅ He can **use** Linux.

---

## 3. بعد از Do / Does / Did

بعد از `do / does / did`، فعل به **Base Verb** برمی‌گردد.

### Present Simple

> Do you **work** here?  
> Does he **know** Linux?

### Past Simple

> Did you **go** there?  
> Did she **use** the server?

دقت کن:

❌ Did you **went** there?  
✅ Did you **go** there?

چون `did` خودش زمان گذشته را نشان می‌دهد، فعل اصلی Base Verb می‌شود.

---

## 4. Imperative — دستور دادن

برای دستور دادن، معمولاً جمله را با **Base Verb** شروع می‌کنیم.

> **Open** the file.  
> **Run** the command.  
> **Check** the permissions.  
> **Start** the server.  
> **Stop** the service.

ساختار:

```
Base Verb + ...
```

مثلاً در Linux:

```
Run the command.
Check the file.
Open the terminal.
```

---

## 5. Infinitive — To + Base Verb

یکی از مهم‌ترین ساختارها:

```
to + base verb
```

مثلاً:

> I want **to learn** Linux.  
> I need **to work**.  
> I want **to understand** this.

اینجا:

`to learn`  
`to work`  
`to understand`

همگی از **to + Base Verb** ساخته شده‌اند.

❌ I want to **learned** Linux.  
✅ I want to **learn** Linux.

---

## 6. بعد از بعضی فعل‌ها مثل Make و Let

بعد از `make` و `let` معمولاً Base Verb می‌آید.

### Make

> They made me **work**.

### Let

> Let me **help** you.

نه:

❌ Let me helping you.  
✅ Let me **help** you.

---

## 7. Conditional

در بعضی Conditionalها هم Base Verb داریم.

مثلاً First Conditional:

```
If + Present Simple, will + Base Verb
```

> If you **study**, you will **learn**.

اینجا `learn` بعد از `will` به شکل Base Verb آمده.

### خلاصه‌ی خیلی مهم

Base Verb را بیشتر در این الگوها می‌بینی:

```
I/You/We/They + Base Verb
Modal + Base Verb
do/does/did + Base Verb
Imperative → Base Verb
to + Base Verb
make/let + object + Base Verb
```

مثلاً:

```
I work.
He can work.
Did you work?
Work!
I want to work.
Let me work.
```
