# V3 — Past Participle

## کجاها V3 استفاده می‌شود؟

1. **Present Perfect** → `have/has + V3`
2. **Past Perfect** → `had + V3`
3. **Future Perfect** → `will have + V3`
4. **Passive Voice** → `be + V3`
5. **Perfect Passive** → `have/has/had + been + V3`
6. **به‌عنوان صفت (Past Participle Adjective)** → مثل `broken`, `written`, `closed`

---

## 1. Present Perfect

ساختار:

```
Subject + have/has + V3
```

مثال:

> I **have learned** Linux.  
> She **has finished** the work.  
> They **have gone** home.

اینجا:

`learned`، `finished`، `gone` → **V3**

نکته:

```
I/You/We/They → have + V3
He/She/It → has + V3
```

---

## 2. Past Perfect

ساختار:

```
Subject + had + V3
```

مثال:

> I **had finished** the work.  
> She **had gone** home.  
> They **had learned** the basics.

`had` برای همه فاعل‌ها یکسان است.

---

## 3. Future Perfect

ساختار:

```
Subject + will have + V3
```

مثال:

> I **will have finished** the work.  
> They **will have completed** the project.

---

## 4. Passive Voice

یکی از **مهم‌ترین کاربردهای V3**، Passive است.

ساختار کلی:

```
be + V3
```

مثلاً:

> The file **is deleted**.  
> The server **was restarted**.  
> The command **was executed**.

اینجا:

`deleted`  
`restarted`  
`executed`

همگی V3 هستند.

در مباحث Linux و Nginx هم Passive Voice زیاد می‌بینی:

> The file was **created**.  
> The service was **started**.  
> The configuration was **changed**.

---

# 5. Perfect Passive

اینجا چند ساختار با هم ترکیب می‌شوند:

```
have/has/had + been + V3
```

مثلاً:

> The file **has been deleted**.

یعنی:

- `has` → Perfect
- `been` → V3 فعل `be`
- `deleted` → V3 فعل `delete`

مثال دیگر:

> The server **has been restarted**.

---

# 6. V3 به‌عنوان صفت

گاهی V3 نقش adjective دارد.

مثلاً:

> a **broken** file  
> a **closed** door  
> a **written** document  
> a **deleted** file

اینجا V3 لزوماً بخشی از یک Perfect یا Passive نیست؛ می‌تواند نقش صفت داشته باشد.

## ⭐ فرمولی که باید در ذهنت بماند

```
V1 = Base Verb
V2 = Past Simple
V3 = Past Participle
```

و کاربردهای اصلی:

```
Present Perfect
have/has + V3

Past Perfect
had + V3

Future Perfect
will have + V3

Passive
be + V3
```

مثلاً فقط با فعل `write`:

```
V1 → write
V2 → wrote
V3 → written
```

> I **write** documentation.  
> I **wrote** documentation yesterday.  
> I have **written** the documentation.  
> The documentation was **written** by me.

**پس V3 را بیشتر با `have/has/had` در Perfect و با `be` در Passive می‌بینی.**
