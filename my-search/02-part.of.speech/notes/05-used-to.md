اگر منظورت **ساختار `used to` در زبان انگلیسی** است، توضیحش این است:

## Used to چیست؟

**`used to + base verb`**

برای صحبت درباره‌ی **عادت‌ها، کارها یا وضعیت‌هایی در گذشته که الان دیگر درست نیستند** استفاده می‌شود.

یعنی:

> کاری در گذشته مرتب انجام می‌شد یا یک وضعیت در گذشته وجود داشت، اما الان تغییر کرده است.

### ساختار:

### جمله مثبت:

```
Subject + used to + verb (base form)
```

مثال:

```
I used to play football.
```

یعنی:

من قبلاً فوتبال بازی می‌کردم (اما الان دیگر بازی نمی‌کنم).

---

### جمله منفی:

دو حالت رایج:

```
Subject + didn't use to + verb
```

یا:

```
Subject + never used to + verb
```

مثال:

```
I didn't use to like coffee.
```

من قبلاً قهوه دوست نداشتم.

---

### سوالی:

```
Did + subject + use to + verb?
```

مثال:

```
Did you use to live here?
```

آیا قبلاً اینجا زندگی می‌کردی؟

نکته:  
بعد از **did**، شکل درست **use to** است، نه **used to**.

---

## چه زمانی استفاده می‌شود؟

| کاربرد             | مثال                       |
| ------------------ | -------------------------- |
| عادت قدیمی         | I used to smoke.           |
| وضعیت قدیمی        | She used to be shy.        |
| چیزی که تغییر کرده | We used to live in London. |
|                    |                            |

### خلاصه یک‌خطی:

**Used to = کاری یا حالتی که در گذشته وجود داشت ولی الان دیگر وجود ندارد.**

فرمول حفظی:

```
Past habit/state → used to + verb
```

مثال کلیدی:

```
I used to study English.
```

= قبلاً انگلیسی می‌خواندم (الان شاید دیگر نمی‌خوانم).
